# Entertainment Hub 공개 운영 규칙

- 공개 사이트에는 사용자에게 필요한 검증된 작품·음악·굿즈 정보만 제공한다.
- 원본 수집 경로, 원본 스냅샷, 수집 알고리즘 및 비밀 자산은 비공개 별도 저장소에서 관리한다.
- 공식 출처/검증일/감상 또는 구매 가능 여부(변동 가능)를 명확하게 표시한다.
- 영상·음원·대본·긴 가사·무단 이미지 복제를 피하고 합법적 링크 및 허용된 임베드를 이용한다.
- 중요한 변경은 PR 검토, 기존 파일 보존, 실제 링크 및 모바일 UI 테스트 후 적용한다.
- 자동 수집·포스팅·알림은 사전 검토 없이 켜지 않는다.
