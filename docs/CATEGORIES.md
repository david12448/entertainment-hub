## OST 전용 탐색
- 작품 매체: 영화 / 드라마 / 애니 / 게임 / 뮤지컬 / 다큐
- 보컬 여부: **가창 OST / 기악 OST / 보컬·연주 혼합**
- 음악 용도: 오프닝 / 엔딩 / 삽입곡 / 메인 테마 / 캐릭터 테마 / 배경음악(스코어)
- 음악 장르: 발라드 / 클래식 / 록 / 팝 / 전자음악 / 기타(복수 적용)
- 상세 페이지: 곡·작곡가·가수·연주자·공식 감상처·해당 작품/회차·OST 앨범·CD/LP판본
- 긴 가사/대본이나 무단 업로드 영상·음원 없이 공식 링크와 독자적 설명 중심

OST라는 '작품 속 쓰임새'와 발라드·재즈 같은 '음악 스타일'은 다른 필터다. 가창 OST도 드라마 OST이자 발라드일 수 있다.

## 다른 프로젝트와 연결
공연·팝업 일정과 예매 정보는 문화이벤트, 촬영지·성지순례는 여행, 식당은 맛집 프로젝트의 확인된 데이터로 연결한다. 엔터테인먼트는 작품과의 관련성/팬덤 관점의 설명을 맡는다.
