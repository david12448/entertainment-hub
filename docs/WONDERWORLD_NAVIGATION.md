# Prince In Wonderworld와 공통 탐색

## 사이트 역할
- 티스토리: 작품·시리즈·방송별 종합 허브와 연도/국가/장르·회차 선택
- 블로그스팟: 방송 한 회차별, OST 개별 트랙·앨범, 피규어·굿즈, 명대사/명장면 해설
- 엔터테인먼트 공개 허브: 작품/팬덤 검색과 카테고리별 탐색 기능. 각 사이트 본문 무단 복제 금지

## 사용자 이동 구조
작품 → 회차 → 캐릭터 → OST(가창/기악) → OST 앨범 → 피규어/굿즈 → 관련 작품·공식 영상.

두 블로그의 공통 메뉴/색채를 유지하고, 기존 아이콘형 양방향 링크의 장점을 살린다.
기존 SBS PC의 정상 동작하는 회차 탐색/게시글 주소는 유지한다.
select 메뉴와 함께 접근성 및 검색엔진을 위한 일반 HTML 회차 링크를 제공한다.
실제 저작물 이미지·노래·영상·대사 사용은 이용 조건과 저작권을 확인한다.
클릭 가능한 외부 링크의 최종 주소는 사용자 브라우저에서 확인할 수 있으므로 완전 은닉을 보장하지 않는다.

## 콘텐츠 중복 방지
티스토리는 '작품을 한눈에 보는 요약/목록', 블로그스팟은 '회차/제품/곡의 고유 상세 해설'에 집중한다.
실제 블로그 수정과 배포는 HTML 백업 및 모바일·링크 테스트 후 진행한다.
